# Gaza Kitchen

موقع ويب كامل باسم **Gaza Kitchen** مبني باستخدام:
- HTML
- CSS
- JavaScript
- Node.js + Express

## المميزات
- عرض وصفات غزة التقليدية ووصفات الحرب
- البحث باسم الوصفة أو بالمكونات
- صفحة تفاصيل لكل وصفة
- لوحة أدمن لتسجيل الدخول
- إضافة / تعديل / حذف الوصفات
- إحصائيات للموقع:
  - عدد الزيارات
  - عدد الزوار الفريدين
  - عدد الوصفات
  - أكثر كلمات البحث
  - أكثر الوصفات مشاهدة
  - آخر نشاط إداري

## تشغيل المشروع

```bash
npm install
node server.js
```

ثم افتح في المتصفح:

```bash
http://localhost:3000
```

## بيانات دخول الأدمن الافتراضية
- البريد: `admin@gazakitchen.local`
- كلمة المرور: `123456`

يمكن تغييرها من ملف البيئة `.env` أو من متغيرات الاستضافة.

## ملاحظات
- البيانات محفوظة داخل ملفات JSON في مجلد `data` لتسهيل الفهم والمناقشة.
- هذا مناسب جدًا كمشروع تخرج أو مشروع جامعي لأن الكود بسيط وواضح.
